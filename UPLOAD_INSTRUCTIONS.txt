ZEYN Listening Portal Offline V3

This version uses selective offline downloads:
- Portal pages are available offline after the first visit.
- Each student downloads only the test audio they need.
- The phone does not automatically download all 27 large MP3 files.

Upload:
1. Extract this ZIP.
2. Copy ALL files to the root of the GitHub repository named audio.
3. Replace existing files.
4. Commit to main and Push origin.
5. Open:
   https://zeyn-tedris-merkezi.github.io/audio/?v=3
6. Use Ctrl+F5 or an Incognito window if an older design appears.

Testing offline:
1. Open a test while connected to the internet.
2. Press “Download for Offline”.
3. Wait until “Saved Offline” appears.
4. Turn off internet and reload that test.
