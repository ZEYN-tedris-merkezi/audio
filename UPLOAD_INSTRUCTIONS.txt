ZEYN LISTENING PORTAL V4

UPLOAD
1. Extract the ZIP.
2. Copy ALL files into the root of the GitHub repository named audio.
3. Replace existing files.
4. Commit to main.
5. Push origin.

OPEN
https://zeyn-tedris-merkezi.github.io/audio/?v=4

IMPORTANT
Because an older Service Worker may remain in the browser:
- Open the new link in Incognito first, or
- Press Ctrl+F5.
- If needed: Chrome Settings > Privacy > Site settings > View permissions/data
  and remove stored data for zeyn-tedris-merkezi.github.io.

OFFLINE TEST
1. Open a test while online.
2. Press Download for Offline.
3. Wait for “Saved Offline”.
4. Turn off internet.
5. Reload that same test.
